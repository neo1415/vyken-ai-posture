# Layout Components

Shell and page layout wrappers.

| Component       | Purpose                                               |
| --------------- | ----------------------------------------------------- |
| `PublicShell`   | Public site header, main, footer                      |
| `AdminShell`    | Admin placeholder header and main (not authenticated) |
| `PageContainer` | Max-width and horizontal padding                      |

All are Server Components. Route layouts in `src/app/` compose these shells.
