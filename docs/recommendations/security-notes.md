# Module 9 — Security Notes

## Deterministic recommendations only

All findings and recommendations are generated by deterministic in-process engines. No LLM or external API calls.

## Server-only persistence

- `assessment-recommendations.repository.ts` and `assessment-recommendations.service.ts` use `import "server-only"`.
- Verification script (`verify-module9.ts`) uses pure engines + script DB access — it does not import server-only services.

## No legal/compliance claims

Generated text avoids banned terms (certified, compliant, audit passed/failed, guaranteed, breach confirmed, safe/unsafe to use). Validation rejects outputs containing these phrases.

## No report generation

This module does not create `reports`, `leads`, or send email.

## No sales CTA

`cta_type` is stored as `null`. No Calendly, PDF download, or contact-sales CTAs in Module 9.

## No client-generated recommendations

The results placeholder displays counts only. Recommendation generation runs server-side.

## No broad RLS policies

Uses existing Module 3 RLS plan (server-only access). No new public policies added.

## No raw DB IDs in UI

Results placeholder uses public session token only.
